# Logo 来源候选

[source-candidates.json](source-candidates.json) 是待完成收录审核的来源队列，目前有 45 条候选。候选不提供正式 Logo 下载，不计入素材库的品牌或文件数量。正式可下载文件及逐文件依据以 `logos/<id>/metadata.json` 为准。

- `unreviewed`：尚未核查的方向；官网入口也仍待确认，空的 `sourcePages` 不代表已确认素材来源。
- `review-needed`：已检索来源或取得待审核原件，但高清、当前版本、身份、独立文件格式或分发依据仍有缺口。具体进展见 `note`，不表示已经授权。
- `permission-needed`：查到官方来源或使用规范，但当前证据不足以支持独立 Logo 资源库镜像分发。`reviewedAt` 是核查日期，不是授权日期。
