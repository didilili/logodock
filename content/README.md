# Logo 来源候选

[source-candidates.json](source-candidates.json) 是尚待核查的收录方向，包含国内外互联网和 AI 品牌的名称、官网入口与来源状态。已完成收录的公司会从候选清单移出；当前剩余 18 个候选不提供 Logo 文件、图片预览或下载入口，不计入已收录品牌或素材数量。

- `unreviewed`：尚未核查品牌素材及分发条件；官网入口也仍待本轮后续核对。没有 `reviewedAt`，空的 `sourcePages` 不表示已确认官方素材来源。
- `permission-needed`：已查到官方来源或使用规范，但当前证据不足以支持在独立 Logo 资源库中镜像分发。`reviewedAt` 是本次来源核查日期，不能作为授权日期；`note` 说明本轮结论，`sourcePages` 保留官方依据。

剩余候选中，DeepSeek、GitHub、OpenAI 和 Hugging Face 四项保留已查到的来源限制，其余 14 项为 `unreviewed`。官网提供下载、公开代码仓库以及软件或模型采用 MIT 等开源许可，均不能自动证明 Logo 可以由本库再分发。候选名单中没有推定授权、占位图或第三方临摹版本。

腾讯等已收录条目的具体文件、来源与分发依据以 `logos/<id>/metadata.json` 为准。例如，腾讯条目采用 Commons 对具体文字标识的公共领域判定，不代表腾讯官方媒体库的报道用途条款被改为通用分发许可。

获得能覆盖实际文件与镜像分发的明确依据后，再把官方原件和逐文件权利记录加入 `logos/<id>/`；经过仓库校验与索引生成后，才成为可下载资源。网页及根索引只读取已收录的 `logos/` 元数据，不应把此候选清单混入资源卡片、搜索数量或下载目录。
