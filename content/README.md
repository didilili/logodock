# 收录建议

[source-candidates.json](source-candidates.json) 保存尚待核对的品牌、来源线索和待补版本，供社区补充资料。正式可下载素材及逐文件依据见 `logo/<id>/metadata.json`。

候选状态采用以下含义。

- `unreviewed` 表示来源与版本尚待核对。
- `review-needed` 表示已有线索，身份、版本、质量、格式或权利状态仍有待确认项。
- `permission-needed` 表示现有依据尚待补充分发范围的确认。

候选资料按 [贡献指南](../CONTRIBUTING.md) 核对后入库。公开记录保留品牌、实际来源、状态与具体缺项，详细批次日志、下载草稿和比对证据在维护者独立采集档案中维护。
